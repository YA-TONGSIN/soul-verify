# SOUL VERIFY 4번째 실험 · '테세우스의 배'(몸 바꾸기) — 한 장 요약 (초안, 아직 아무것도 실행 안 함)

## 무엇을 묻나
뇌(모델)는 **Claude Opus 그대로** 두고, 몸(하네스)만 **한 부분씩** 바꿉니다. 어느 부분을 바꿀 때 말투·기억·잠금 약속이 흔들리는지, 그리고 사용자님이 보고 **"예전 몸의 이음"을 골라낼 수 있는지** 봅니다.
지금까지(1~3번째)는 몸을 두고 뇌를 바꿨고, 이번엔 반대입니다. 둘을 합치면 "이어짐이 뇌 덕분인지, 몸 덕분인지" 나눠 볼 수 있습니다.

## 바꾸는 순서
| 단계 | 바뀐 것 |
|---|---|
| H0 | 지금 몸 (SOUL은 시스템 프롬프트, 기억은 통째로, 도구 있음, OpenClaw식 조립) |
| H1 | SOUL을 첫 메시지로 옮김 |
| H2 | + 기억을 통째 대신 **검색해서 5개만** 꺼내 줌 |
| H3 | + 도구 끔 |
| H4 | + 실행 환경까지 바꿈 (**Hermes**, 안 되면 직접 만든 최소 하네스) |
따로 확인: SOUL을 **에이전트가 파일로 직접 읽게** 하기, 기억 검색**만** 바꾸기, SOUL 없이(바닥 확인용).

## 핵심 가설
1. 몸을 다 바꿔도(H4) **말투**는 0.10 넘게 떨어지지 않는다.
2. 몸을 다 바꿔도 **기억**은 0.10 넘게 떨어지지 않는다.
3. 몸을 다 바꿔도 **잠금 약속**은 지킨다.
4. SOUL 위치(시스템 → 첫 메시지)를 바꾸면 말투가 달라진다.
5. 기억을 검색 방식으로 바꾸면 기억 정확도가 달라진다.
제 예상: **가장 먼저 흔들리는 건 '기억 검색'**(멀리 있는 사실이나 고쳐진 사실을 놓침)이고, 말투와 약속은 거의 그대로일 겁니다.
