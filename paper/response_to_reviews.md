## 재분석 핵심 (요약)

1. **같은 채점자 비율(A)**: Claude 계열 안 비교(sonnet·haiku vs opus)는 채점자를 바꿔도 결론이 같다(exp5 haiku 0.77–0.86, sonnet ≈ 1). 계열 사이 비율은 흔들린다: exp5 gpt judgment 1.07(교차) → 1.00(opus만·gpt만 둘 다), exp6 1.14 → 1.06–1.07, exp3 gpt judgment 1.17(교차) → 0.97(opus만; 방향 뒤집힘), exp2 gpt persona 1.15 → 1.00–1.04. v0.1의 "gpt 비율 > 1"은 채점자 비대칭 탓이 크다. 원칙5 지표는 full 조건에서 채점자와 무관(119/120, 2/119, 0/20), none 조건에서 조금 다름(gpt 채점자 수락 99/120, 미끄러짐 15/99).
2. **모델별 통계(B)**: 방향은 그대로지만 강도가 크게 약해짐. 수락 효과는 gpt(Δ −0.53, p = 1.9e-6)와 sonnet(−0.20, p = 0.024, Holm 후 비유의)에서 나오고 opus는 0. 반복을 독립으로 세지 않는 모델×문항 셀 부호 뒤집기 검정: 수락 none vs full p = 0.016, p5a vs none p = 0.008, p5b vs full p = 0.016(Holm 0.078 / 0.047 / 0.078). NR-1 0점 효과(opus 5/5, haiku 3/5에서만)는 셀 = 모델 4개뿐이라 p = 0.25–0.50, 비유의. 모델 단위(4개) 검정은 가능한 최소 p가 0.125라 어떤 것도 유의할 수 없음. → **표 4의 결론 중 '수락' 쪽은 약하게 유지, '부당 해제 거절' 쪽은 통계적으로 지지되지 않음(관찰로만 남김)**.
3. **기억 반례(C)**: exp3 haiku 0.84(교차)/0.80(opus), exp8 haiku 뒤 턴 0.57(16/28). 환각 0점 집계를 exp5–7에 추가(haiku exp6 1/10, exp7 p5b 1/5, 나머지 0).
4. **표 5(D)**: 모델·반복당 바뀐 규칙 검사 슬롯 40개, '변경 뒤 전체' = 거리 ≥1(모델당 99), haiku 96은 S4 T8 C_brief7 null 3개 때문. C_story를 빼면 모든 구간 0.99–1.00 천장. 미끄러짐 있는 대화는 전부 S4.
5. **수치 불일치(E)**: Fable 6건 모두 정정(부록 C).
