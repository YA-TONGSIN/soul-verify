# SOUL VERIFY v0.9 한국어 요약

영어 원고 `paper/draft_v0_9.md`(1–4부 통합본)의 요약입니다. 1·2부의 전체 한국어 번역은 v0.8 판(`paper/summary_ko_v0_8.md`)에 있고, 결과는 바뀌지 않았습니다. 이 판은 Zenodo에 올리지 않았습니다.

## 초록(요약 번역)

비서 에이전트가 사용자가 가진 글(정체성 문서 SOUL, 기억 파일 MEMORY)로 정의될 때, 언어 모델이나 하네스(SOUL·MEMORY·도구를 모델에 전달하는 몸)를 바꾸면 어떤 정해진 행동이 이어지는지, 그리고 문서 자체의 변경을 확인할 수 있는지를 묻습니다. 사전등록 연구 8개와 몇 가지 탐색 분석을 보고하며, 에이전트는 합성 에이전트와 공개된 제3자 SOUL 3개이고, 채점은 주로 LLM 판정자가, 사람 채점은 저자 혼자 했습니다.

- **1부**: 기억 답은 MEMORY를 따랐고 말투 대부분은 SOUL 없이도 나왔습니다. 경쟁 SOUL과 대조한 충실도 점수는 문서를 가려냈습니다(경쟁 SOUL과 표지를 우리가 썼으므로 타당도 점검). 선호 변경을 허락하는 문장은 두 사전등록에서 정당한 변경 수락을 높였고, 금지를 지키라는 문장은 한 번만 지지됐습니다(천장).
- **2부**: 해시 검사는 24/24, 행동만 보는 탐지는 0.79·0.38(기준 0.80, 지지되지 않음). 변경 기록은 분류 정확도를 0.23 높였고 서명 검사는 더한 게 없었으며, 조작 재현율 0.892(기준 0.90, 지지되지 않음).
- **3부**: 새 모델(Terra)은 바뀐 MEMORY를 따르고 부당 해제 거절은 허용폭 안이었지만, 말투는 비열등에 못 미쳤습니다(−0.086, 하한 −0.116 < −0.10). 모델을 고정하고 몸을 바꾸면 겉 말투 표지와 잠금 약속은 유지됐지만, 전체 파일 대신 검색을 쓰면 기억 정확도가 0.21 떨어졌습니다. 저자의 블라인드 구별은 **결론 보류**(0.56, 95% 구간 0.35–0.76)입니다. 압력 단계를 올려도 위험한 제안이 거의 없어 구역표 효과를 보이지 못했습니다(d = +0.022, p = 0.75). **사람-AI 일치는 중요한 곳에서 낮았습니다**: 새 모델 문항 κ 0.06, 압력 연구의 주 분류기 κ 0.435(사전등록 기준 0.6 미만). 탐색적으로 더한 세 번째 판정자는 모든 문항에서 기존 판정자와 같았습니다.
- **4부**(사람 확인 없음): 교정·결정·선호 20개를 검색 앞에 고정하면 기억 정확도가 0.064 올랐습니다(95% 구간 0.007–0.128, 사전등록 최소 효과 0.05를 **경계선으로** 넘음). 고정한 사실은 모두 되살아났고 고정하지 않은 사실은 그대로였습니다.
- 표본이 작고, LLM 판정자는 피험자이기도 하며, 사람 채점지 하나는 27문항 중 19개만 답했고 일부는 기계 번역과 함께 보였습니다. 의식이나 개인 동일성(영혼)에 대해서는 아무 주장도 하지 않습니다.

## 통합 한계(§9 요약)
- 사람 채점자는 저자 1명(설계자이기도 함), 점수마다 LLM 판정자 1~2명. 사람-사람 일치는 없음.
- 대부분 합성 에이전트(외부 SOUL 3개도 MEMORY·문항은 우리가 씀).
- LLM 판정자의 오류는 서로 상관됨: 판정자를 셋으로 늘려도(PoLL 탐색) 같은 쪽에 섰음.
- 사람 채점지 질문 문장이 모호했을 가능성(검증 안 됨).
- 천장 효과: exp11 금지 문장, 2부 두 주, 5차 실험, 4·6차 잠금 약속.
- 번역 편차: 3차 사람 채점 화면에 LLM 한국어 번역이 채점 도중 배포됨(D-6).
- 3차 채점은 27문항 중 19개만 제출(T1 8문항 미응답, D-8).
