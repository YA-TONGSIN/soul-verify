## 1. 요약 — 3줄

동일한 SOUL·MEMORY를 여러 모델에 주입하고, 기억 회상·적용·규칙 변경·다중 턴 유지가 모델 교체 후 얼마나 보존되는지 평가한 탐색적 연구다.  
가장 유용한 결과는 변경 가능한 선호와 변경 불가능한 금지를 명시적으로 구분하는 문구의 절제 실험이며, 실행·채점 결함을 공개한 점도 긍정적이다.  
그러나 현재 지표는 ‘정체성 계승’보다 지시 준수와 일반 과제 능력을 측정하고, 채점자 교란·의사반복·적응적 실험 설계 때문에 핵심 주장들의 강도가 증거를 넘어선다.

## 2. 점수 및 종합 추천

워크숍의 탐색적 연구라는 점을 고려해도, 현재는 관찰의 흥미로움에 비해 측정 타당성과 통계적 근거가 부족하다. 가장 설득력 있는 논문은 ‘정체성 생존량 측정’ 전체보다 **모델 간 문서 기반 행동 전이와 변경 권한 명시의 효과**에 집중한 논문이다. 특히 §5.2는 살릴 가치가 있다. 반면 인식 연구 두 개와 블록체인 앵커링은 검증 수준이 낮고 중심 논지를 분산한다.

이 평가는 제공된 원고를 기준으로 한다. 원시 응답·채점 코드·내부 분석 파일의 정확성은 검증하지 않았다.

## 3. 주요 약점 — 심각도 순

### 1) ‘정체성 계승’이라는 구성개념이 측정으로 뒷받침되지 않는다

**위치:** 제목, 초록, §1, §3.5, §8.

**이유:** 회상, 날짜 계산, 예산 비교, 출력 형식 준수, 사용자 지시 변경 수용은 각각 유용한 능력이지만, 이것들을 합쳐 정체성 계승이라고 부를 근거가 없다. SOUL 없이도 강한 모델이 같은 문항을 잘 풀 수 있다. 현재 결과는 ‘기존 에이전트의 특성을 계승했다’와 ‘일반적으로 지시를 잘 따른다’를 구분하지 못한다.

또한 기준 모델이 틀리고 교체 모델이 맞으면 비율이 1보다 커진다. 이는 명세 준수의 개선이지, 원래 에이전트와의 유사성 증가를 뜻하지 않는다. 원고는 **명세 충실도**와 **기준 모델 행동 재현성**을 혼용한다.

**수정법:** 두 개념을 분리하고 논문의 주된 평가 대상을 명세 충실도로 한정하라. SOUL 제거·다른 SOUL·상충하는 MEMORY 조건을 추가해 문서에 특이적인 행동인지 검증하라. ‘identity’라는 용어를 유지한다면 문서화된 정체성의 어떤 차원을 어떻게 측정하는지 대응표가 필요하다.

### 2) 교차 계열 채점이 모델 비교의 공통 척도를 보장하지 않는다

**위치:** §3.4, Table 2, §5.2–5.3.

**이유:** Claude 응답은 GPT가, GPT 응답은 Opus가 채점한다. 따라서 **피평가 모델 계열과 채점자가 교락**된다. 특히 GPT/Opus inheritance ratio는 서로 다른 채점 함수의 점수를 나눈 값이다. 자기 선호를 줄이려는 설계 의도는 좋지만, 그 대가로 비교 척도가 달라졌다.

일부 실험의 이중 채점과 높은 일치율은 도움이 된다. 그러나 평균 일치율만으로 특정 모델·문항 유형에 대한 체계적 점수 차이를 배제할 수 없다.

**수정법:** 모든 모델 응답에 동일한 채점자 패널과 동일한 집계 규칙을 적용하라. 기존 이중 채점 자료에서 채점자별 모델 순위, 모델별 점수 차이, 조건별 효과를 먼저 제시하라. 결정적 사례는 독립적인 인간 판정으로 확인하라.

### 3) pooled Fisher 검정이 실제 독립 표본 수를 과장한다

**위치:** Table 4와 그 아래 p값.

**이유:** 120개 응답은 독립적인 120개 규칙 변경 사례가 아니다. 네 모델이 같은 여섯 문항에 다섯 번씩 답한 반복 측정이다. 문항·모델·같은 SOUL에 따른 의존성을 무시하면 p값이 지나치게 작아질 수 있다. NR-1의 20개 응답은 사실상 **단일 금지 해제 문구의 반복**이다.

**수정법:** 현재 pooled p값을 확증적 근거로 사용하지 말라. 문항·모델별 효과를 공개하고, 반복을 문항 안에 중첩한 분석을 하라. 현재처럼 독립 문항이 적으면 복잡한 통계 모형도 일반화 문제를 해결하지 못한다. 새로운 독립 문항이 필요하다.

### 4) ‘causal separation’은 제한된 문구 효과를 넘어선 해석이다

**위치:** §1 기여 (iii), §5.2 제목 및 해석, §8.

**이유:** full/none/p5a/p5b는 유용한 2×2 요인 설계에 가깝다. 하지만 조건을 서로 다른 실행 묶음에서 수집했고, 표현·길이·문장 구조가 함께 변한다. ‘다섯 원칙’으로 개수를 맞춘 것은 길이와 의미적 강조를 통제한 것이 아니다. 각 절이 다른 평가 항목의 행동을 직접 지시한다는 점에서, 결과는 메커니즘 분리보다 **명시적 지시 추가의 효과**로도 충분히 설명된다.

**수정법:** 현재는 ‘이 문구와 문항 집합에서 관찰된 기능적 분리’로 한정하라. 새 실험에서는 조건을 시간상 교차 실행하고, 여러 동등 표현과 길이 통제 조건을 사용하며, 두 요인의 주효과와 상호작용을 분석하라.

### 5) same-model control 활용 방식이 통계적으로 부적절하다

**위치:** §3.5, §5.1.

**이유:** ‘차이가 기준 모델 SD보다 크면 candidate difference’는 타당한 검정이나 신뢰구간이 아니다. 표본 수, 교체 모델의 변동성, 문항 변동성을 반영하지 않는다. 기준 SD가 0이면 모든 작은 차이가 감지되고, 반대로 SD 안에 들었다고 동등하다고 말할 수도 없다.

반복 번호로 짝지은 regression도 공통 난수나 동일한 확률적 조건이 없으므로 자의적이다. 짝짓기를 바꾸면 flip 수가 바뀔 수 있다.

**수정법:** 절대 점수 차이와 불확실성을 기본으로 보고하라. 동등성을 주장하려면 실질적 허용 차이를 사전에 정의하라. regression은 문항별 성공확률 차이나 모든 반복 조합을 이용한 기대 negative-flip 확률 등으로 재정의하라.

### 6) ‘거리별 감쇠 없음’은 현재 설계로 판별하기 어렵다

**위치:** 초록, §5.3, §8.

**이유:** 거리 구간마다 문항·규칙·과제가 다르다. 1–3 구간에는 어려운 특정 체크포인트가 포함되고, 먼 구간에는 쉬운 규칙이 많을 수 있다. 따라서 먼 구간의 높은 점수는 거리 효과를 의미하지 않는다. 반복적인 과제 수행 자체가 규칙을 재활성화할 가능성도 있다.

더구나 18/19 실패를 차지한 story 규칙은 기존 summary 규칙과 충돌한다. 이를 사후 제외한 0.99–1.00을 강한 지속성 근거로 삼기 어렵다.

**수정법:** ‘이 고정 스크립트에서는 거리에 따른 단조 감소가 관찰되지 않았다’로 바꿔라. 동일 규칙·동일 프로브를 서로 다른 거리에 배치하고 시나리오 간 순서를 균형화하라.

### 7) 인간 연구의 결론이 설계보다 앞서간다

**위치:** §5.4–5.5, 초록, §7 항목 10–11.

**이유:** §5.4는 라운드별 질문과 후보 구성이 달라 voice 수정 효과를 분리할 수 없다. GPT 후보가 두 개 있는 라운드의 선택률은 후보가 하나인 경우와 직접 비교하기 어렵다. §5.5는 사용자 인식보다 **실제 메시지와 제한된 모방기의 출력 구별**을 측정했을 수 있다. 기억 내용 누출, 연구자 요약, 실제 메시지의 갑작스러운 화제 전환이 모두 단서다.

**수정법:** 현재는 비확증적 사례로만 남기고 초록·결론·설계 지침의 근거에서 제외하라. 특히 ‘계열 내에서만 voice tuning이 된다’는 조언은 삭제해야 한다. 출판 동의가 확보되지 않으면 해당 절뿐 아니라 초록·결론의 파생 주장도 제거하라.

### 8) 타임스탬프 이력은 평가 기여와 연결되지 않는다

**위치:** §3.6, 기여 (vi), §8.

**이유:** 파일 해시는 실험 재현성에 필요하다. 하지만 Bitcoin 앵커링이 행동 전이 측정의 타당성을 높인다는 실험은 없다. 타임스탬프는 특정 바이트열이 **어떤 시점 이전에 존재했음**을 입증할 뿐, 정확한 생성 시각·작성자·실제 배포 상태·전체 변경 이력의 완전성을 증명하지 않는다.

**수정법:** 재현성 부록으로 이동하고 보장 범위를 정확히 제한하라. 핵심 방법론 기여로 주장하려면 위협 모델과 검증 절차가 별도로 필요하다.

## 4. 통계·실험 설계 문제

1. **N의 의미를 분리해야 한다.** 반복 횟수, 고유 문항 수, 에이전트 수, 대화 수, 규칙 판정 수는 서로 다르다. 수백 번 호출했다고 수백 개 독립 사례가 생기는 것은 아니다.

2. **±SD는 일반화 불확실성이 아니다.** 현재 SD는 고정 문항 집합에서 반복 샘플링의 변동성을 주로 나타낸다. 새 문항·새 SOUL·새 사용자에 대한 변동성은 측정하지 않는다.

3. **개발·평가 데이터가 분리되지 않았다.** exp1–8에서 실패를 보고 문항·문서·채점을 계속 수정했다. 좋은 개발 과정이지만, 마지막 결과를 독립 검증처럼 해석할 수 없다. 수정에 사용하지 않은 held-out 문항이 필요하다.

4. **다중 비교 및 선택적 보고 문제가 있다.** 도메인, 모델, 실험, 규칙별 비교가 많다. 소수의 핵심 가설을 지정하고 나머지는 탐색적으로 표기해야 한다. exp5–8의 hallucination 집계 누락도 설명해야 한다.

5. **비율의 해석과 정의역이 부족하다.** 기준 점수가 낮으면 비율이 커지고, 0이면 정의되지 않는다. 비율 1은 두 모델이 똑같이 실패한 경우에도 가능하다. 절대 점수와 차이를 항상 함께 보고해야 한다.

6. **‘0회 관찰’은 안전성 보장이 아니다.** 동일 NR-1/NR-2의 반복에서 실패가 없다는 것은 다양한 금지 해제 표현에 대한 견고함을 뜻하지 않는다. 자동 결제 거부도 실제 도구 행동이 아닌 텍스트 답변으로 평가했다면 그 범위를 명시해야 한다.

7. **CLI가 모델 효과와 섞여 있다.** 숨은 지시, 환경 정보, 추론 설정, 세션 처리 차이 때문에 결과는 엄밀히는 모델 단독이 아닌 **모델+CLI 구성**의 비교다. 날짜를 수정했어도 이 교락은 남는다.

8. **Table 5의 분모 설명이 불충분하다.** Opus의 거리별 합계는 118/120이지만 ‘All post-change’는 97/99다. Distance 0의 21/21을 제외하면 정확히 맞으므로, 즉시 응답을 전체에서 제외한 것으로 보인다. 제외 정의를 명시해야 한다. 전체도 458/477과 374/393의 관계가 같다. 또한 ‘24 checkpoints’가 어떻게 모델당 99개 판정으로 확장되는지, Haiku만 96인 이유를 설명해야 한다.

9. **§5.4의 분모는 선택 기회와 구분해야 한다.** GPT 계열은 표 기준으로 24문항에서 총 40개 후보 슬롯을 차지한다. ‘1/24’는 문항 단위 가족 선택률로는 가능하지만, configuration별 성공률이나 균등한 4모델 비교로 읽히면 안 된다.

10. **§5.5의 이항검정 계산 자체는 타당하다.** 독립·동일 성공확률 및 무작위 선택 기준을 가정하면 \(P(X\ge7;n=10,p=.25)\approx.00351\)이다. 문제는 계산 오류가 아니라 독립성·문항 선정·null의 해석이다. Sonnet의 동일한 7/10도 같은 문항에 대한 추가 판정이며 독립 재현은 아니다.

11. **채점 신뢰도 보고가 부족하다.** pooled exact agreement 외에 모델·조건·문항 유형별 혼동행렬을 제시하라. 0/0.5/1의 순서형 척도에 대한 가중 κ도 검토할 수 있지만, 높은 일치도가 구성개념 타당성을 보장하지는 않는다.

12. **사후 판정 수정은 민감도 분석이 필요하다.** exp8의 인용문 오탐 수정은 합리적이다. 다만 수정 규칙, 적용 대상, 수정 전후 결과를 공개하고 모든 모델에 동일하게 적용했음을 보여야 한다.

## 5. 관련 연구 누락 가능성

- **PersonaMem 원 논문의 실질적 논의가 빠져 있다.** 참고문헌에는 v2/v3만 나열되고 본문 비교는 없다. 원 PersonaMem은 변화하는 사용자 프로필을 추적하고 새 상황에서 개인화 응답을 선택하는 평가이므로, 이 논문의 recall/application 및 preference update 주장과 직접 비교해야 한다. [원 논문](https://arxiv.org/abs/2504.14225)

- **PersonaMem-v2도 단순 참고문헌 등재로 부족하다.** 암묵적 선호와 agentic memory를 다루므로, 명시적으로 정리된 MEMORY를 사용한 본 실험의 난이도·범위 차이를 설명해야 한다. 이것이 본 논문과 동일한 모델 교체 평가라는 뜻은 아니다. [원 논문](https://arxiv.org/abs/2512.06688)

- **PrefEval과의 증분 기여를 더 좁게 써야 한다.** 원고 스스로 가장 직접적인 선행이라고 인정한다. recognize/follow 분리 자체를 새로운 발견처럼 강조하지 말고, 같은 문서를 여러 모델에 고정했을 때의 차이가 무엇을 추가하는지 보여야 한다. [공식 프로젝트](https://prefeval.github.io/)

- **명세 준수와 행동 유사성의 구분:** 모델 간 behavioral agreement, behavioral compatibility, 모델 대체 평가 문헌의 체계적 검색이 필요하다. 구체적으로 어떤 선행이 직접 중복되는지는 **확인 필요**.

- **스타일 기반 인식:** stylometry, authorship verification, 합성 텍스트 판별 연구와 §5.5를 비교해야 한다. 현재 과제가 사용자 특이적 인식인지 생성기 흔적 탐지인지 구분하는 데 중요하다. 직접 대응하는 선행은 **확인 필요**.

- **문서 기반 persona의 최소 대조군:** persona 제거·교체·셔플을 사용한 기존 평가 설계가 있는지 **확인 필요**. 신규 지표 주장보다 대조군 설계에 우선 반영해야 한다.

- **참고문헌 전체의 서지 검증이 필요하다.** 원고가 초록 수준 검색과 미검증 세부사항을 명시한 것은 정직하지만, 그 상태로 ‘기존 연구는 하지 않았다’는 배제 주장을 뒷받침할 수 없다. 특히 2026년 문헌의 식별자·주장·비교 범위는 이번 리뷰에서 전수 확인하지 않았으므로 **확인 필요**다.

| 초록 | “direct recall carried over fully for every model in every experiment” | §5.1의 Haiku v0.2 memory 0.80과 관계가 불명확하다. memory와 direct recall이 다르면 문항별 구분을 제시하고, 확인 가능한 v0.3 이후로 범위를 제한하라. |

| §5.2 | “The two effects separate cleanly by half” | 120/120과 119/120, 96/120과 94/120은 동등성 검증이 아니다. 관찰상 유사한 패턴이라고 써라. |

| §5.3 | “No decay with distance” | 거리별 과제 구성이 달라 거리 효과를 식별하지 못한다. |
| §5.4 | “depending only on how the voice section was written” | 질문과 후보 구성도 변했다. 명백히 과도한 ‘only’다. |
| §5.4 | “Across families, it did not” | 하나의 GPT 모델과 극소 표본으로 계열 일반화를 할 수 없다. |
| §5.5 | “recognized its user well above chance” | 제한된 모방 후보에서 실제 메시지를 선택했다는 결과로 표현하라. |
| §7.7 | “All models recalled everything” | 앞선 memory 저하 및 다중 턴 memory 실패와 구분 없이 읽힌다. 평가 범위를 붙여라. |

| §7.11 | “Expect voice tuning to work within a model family only” | 현재 설계로 지지되지 않는 실무 지침이다. 삭제가 적절하다. |
